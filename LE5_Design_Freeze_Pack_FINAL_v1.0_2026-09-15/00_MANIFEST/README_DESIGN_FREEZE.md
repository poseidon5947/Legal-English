# Legal English 5 Design Freeze Pack v1.0

Date: 15 September 2026  
Status: FINAL — APPROVED / FROZEN / READY FOR CARLOS HANDOFF

## Freeze scope

This package is the implementation authority for the Legal English 5 website visual system. The Owner has approved and frozen:

- L01–L07: primary logo, monogram, favicon package and social avatar.
- P01–P07: approved photography masters and responsive exports.
- I01–I04: 37 individual SVG icons, family sprites and visual specifications.
- D01: eight desktop compositions.
- D02: nine mobile compositions.
- D03: component and state sheet.
- D04: reconciled design tokens and developer-readable JSON.

There are no outstanding production-asset blockers within this Design Freeze Pack.

## Implementation controls

- Implement the supplied production files without redrawing, substituting, recoloring, relabeling, recropping or visually reinterpreting them.
- Delivery optimization is permitted only when it preserves the approved appearance, dimensions, aspect ratios and color values.
- Use `Area / Areas` in all learner-facing interfaces. `Category / Categories` remains internal terminology only.
- EN / ES must remain visible in desktop and mobile interfaces as shown in the approved compositions.
- Use the complete `BY MPC LAW STUDIO` endorsement in the primary logo.
- Use the monogram when the primary logo cannot meet its minimum digital width of 260 px.

## Folder map

- `00_MANIFEST`: approval record, asset register, design-token JSON, checksum inventory and implementation handoff.
- `01_LOGO_PRODUCTION_APPROVED`: L01–L07 production assets.
- `02_PHOTOGRAPHY`: P01–P07 approved masters and responsive exports.
- `03_ICONOGRAPHY_SVG_APPROVED`: production SVG icon families.
- `03_ICONOGRAPHY_VISUAL_SPECS`: approved visual reference sheets.
- `04_UI_SYSTEM`: D03 component/state sheet and D04 tokens.
- `05_DESKTOP_COMPS`: D01 approved desktop compositions.
- `06_MOBILE_COMPS`: D02 approved mobile compositions.
- `99_CONTROLLED_REFERENCES`: governing and traceability references; these are not production assets.

## Change control

Any visual change after this freeze requires a documented change request, impact review and new Owner approval before implementation.
